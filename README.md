## Features

- Multi-page website layout
- Responsive design using Bootstrap
- Home page with hero banner
- About section
- Product showcase section
- Image gallery section
- Contact form and embedded map
- Newsletter subscription section

## Tech Stack

- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery

## Pages Included

- `index.html` - Home page
- `about.html` - About page
- `product.html` - Product page
- `gallery.html` - Gallery page
- `contact.html` - Contact page

## How It Works

- The homepage introduces the business with a banner and featured sections
- The About page provides company information
- The Product page displays available fruit products
- The Gallery page showcases images
- The Contact page includes a form and map for user communication
